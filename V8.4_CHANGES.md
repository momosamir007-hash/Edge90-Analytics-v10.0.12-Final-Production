# Edge90 Analytics v8.4 — Model Registry & Champion–Challenger System

## New lifecycle layer
- Added a per-league `ModelRegistry` under `models/registry/<league>/`.
- Records Challenger candidates, evaluation metrics, promotion/rejection decisions, reasons, and measured improvement.
- Maintains the current Champion separately from historical lifecycle events.
- Promotion remains governed by the conservative leakage-safe v8.3 pipeline; the registry does not weaken validation gates.
- Uses atomic JSON persistence and version/league compatibility checks.

## Flow
Drift → Candidate → Temporal Validation → Walk-Forward / holdout evidence → Champion comparison → Promote or reject → Registry history.

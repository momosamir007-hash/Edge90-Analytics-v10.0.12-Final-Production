# Edge90 Analytics v8.5 — Shadow Deployment & Live Model Evaluation

## Purpose
V8.5 introduces a conservative shadow lane for Challenger models. The Champion remains the only model whose prediction is exposed to users.

## Flow
Champion prediction -> user output

Challenger prediction (when supplied by a compatible candidate runtime) -> silent storage

Resolved real result -> live Log Loss comparison -> promotion recommendation only with sufficient evidence.

## Safety gates
- Minimum 30 resolved live fixtures with both predictions.
- Challenger must improve live Log Loss by at least 0.01.
- A `promote_recommended` result is a recommendation, not an automatic overwrite.
- Missing challenger probabilities are never fabricated.
- JSON state is protected by version/league checks and atomic writes.

## API
`ShadowDeploymentManager.activate(...)` activates a Challenger.
`record_prediction(...)` stores parallel probabilities.
`resolve(...)` attaches the observed outcome (0=Home, 1=Draw, 2=Away).
`evaluate()` compares Champion and Challenger on resolved live fixtures.

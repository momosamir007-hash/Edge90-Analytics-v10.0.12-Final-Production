# Edge90 Analytics v10.0.1 — Verification & Integration Fix

## Fixed
- Fixed the Walk-Forward runtime crash caused by `Engine.predict()` assuming that every Engine instance has a live `drift_detector`.
- Backtest/temporal Engine instances now explicitly support an absent live drift detector and use a neutral drift factor (`1.0`) with no drift alerts.
- Production Engine instances continue to receive the league-level drift detector and latest drift report.
- Added missing `drift_factor` and `drift_alerts` fields to the slot-based `Pred` object, preventing runtime assignment failures.

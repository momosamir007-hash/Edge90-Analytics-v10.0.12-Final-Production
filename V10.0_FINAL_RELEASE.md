# Edge90 Analytics v10.0 — Final Production Release

## Release scope
v10.0 consolidates the model-quality, lifecycle, safety, governance, explainability, data-integrity, production-hardening, and final-acceptance work completed from v7.6 through v9.4.

→ Canary Monitoring

## Production release rule
This package must not be considered empirically accepted merely because it imports or passes syntax checks. Before enabling a league for production, run:

`LeagueApp.run_final_benchmark_acceptance()`

The league is eligible only when the persisted v9.4 acceptance report returns:

- `acceptance: PASS`
- `safe_for_final_release: true`

## Included release gates
- Chronological Walk-Forward evidence
- Minimum fold and out-of-sample requirements
- Log Loss and Brier Score sanity checks
- Data Quality & Integrity gate
- Data Leakage risk guard
- Production Hardening gate
- Conservative model promotion and rollback protections

## Release philosophy
No component is assumed to improve the system merely because it exists. Activation and promotion remain evidence-gated wherever the corresponding subsystem supports validation.

# Edge90 Analytics v7.1.0

نسخة مطورة من المشروع الأصلي مع التركيز على تقليل أخطاء الهوية وتسرب البيانات وتحسين موثوقية الاحتمالات.

## أهم التغييرات
- هوية موحدة وثابتة للفرق بين CSV وAPI.
- إزالة التكرار باستخدام التاريخ + الفريقين بعد التطبيع، وليس API IDs فقط.
- ترتيب/نقاط/فورم/إحصائيات عميقة محسوبة للموسم الحالي فقط؛ Elo وH2H تاريخيان.
- إعادة بناء Elo من الصفر عند إعادة تشغيل التاريخ، لمنع تسرب Elo محفوظ من المستقبل.
- Temporal CV بدلاً من Shuffle CV لتقييم ML بصورة أقرب للواقع.
- Temperature Scaling مع ضبط إضافي لاحتمال التعادل على مجموعة المعايرة فقط.
- منع Draw Correction من إنتاج boost سالب.
- إزالة Overround من احتمالات السوق قبل المقارنة.
- Downloader يحدّث الموسم الجاري ولا يعتبر الملف القديم مكتفياً، مع معالجة 429 و5xx.
- `audit_project.py` لفحص سلامة البيانات والكود والإعدادات.
- النماذج القديمة v5 محفوظة في `models/legacy/` ولا يتم تحميلها تلقائياً.

## التشغيل

```bash
python audit_project.py
python downloader.py
streamlit run app.py
```

أو CLI حسب الواجهة الموجودة في المشروع.

> ملاحظة: نماذج v7.1 لا يتم تضمينها كملفات binary حتى لا تُفرض نسخة مكتبات ML قديمة على جهازك. التطبيق يعيد تدريبها من البيانات الحالية عند الحاجة.

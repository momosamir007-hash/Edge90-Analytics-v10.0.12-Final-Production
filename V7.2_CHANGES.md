# Edge90 Analytics v7.3 — Walk-Forward Weight Optimization

## What changed
- Added leakage-safe component weight optimization.
- Optimization uses only the chronological calibration window; evaluation matches remain unseen.
- Objective: multiclass log-loss on 1X2 probabilities.
- Candidate weights are sampled on the simplex and compared with the validated v7.1 prior.
- Final weights use 60% prior + 40% optimized candidate to reduce calibration-window overfit.
- Missing components are assigned zero weight; ML is only included when it is actually available.
- Evaluation uses the frozen optimized weights for the entire evaluation window.

## Why
A fixed blend can be suboptimal across leagues and seasons. v7.3 lets the data choose a modest adjustment while preserving a strong prior toward the validated model.

## Important
This does not guarantee more correct predictions. It is designed to improve probability quality and robustness while avoiding look-ahead leakage.

# Edge90 Analytics v10.0.9 Release Notes

**Theme:** Temporal Decision Policy Optimization

This release addresses the v10.0.8 weakness where `select_policy([audit])` evaluated only one fold.

### Promotion rules
A non-Argmax policy may be selected only after:
- at least 3 chronological folds;
- accuracy safety gate vs Argmax;
- predicted-draw-rate drift gate;
- macro-F1 non-inferiority gate;
- minimum win-rate vs Argmax;
- worst-fold accuracy protection;
- macro-F1 stability gate.

Otherwise the system falls back to Argmax.

The probability-generation pipeline is intentionally untouched.

# v8.8 — Post-Promotion Canary Monitoring

## Added
- Canary monitoring after successful v8.7 artifact promotion.
- Baseline vs new Champion Log Loss comparison on resolved live fixtures.
- Minimum evidence threshold of 20 resolved fixtures.
- Sustained degradation confirmation across two evaluation windows.
- Automatic rollback request through the v8.7 SafeArtifactPromotionManager.
- Per-league, version-protected JSON state with atomic saves.

## Safety
Canary monitoring never changes live probabilities. Rollback is triggered only after sufficient live evidence and sustained performance degradation.

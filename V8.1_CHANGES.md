# Edge90 Analytics v8.1 — Contextual Performance Monitor

## New
- Rolling context-aware performance monitor keyed by match regime and confidence band.
- Tracks out-of-sample Log Loss by context and compares it with league baseline.
- Requires at least 30 observations before penalizing a context.
- Automatically reduces displayed prediction confidence when recent evidence shows material deterioration.
- Conservative floor prevents excessive confidence collapse; sparse or unknown contexts remain neutral.
- Version- and league-protected persistence with atomic saves.

## Design principle
Monitoring is a guardrail, not a claim that a model has improved. Context penalties should be validated through chronological walk-forward evaluation before they are promoted into permanent model-selection policy.

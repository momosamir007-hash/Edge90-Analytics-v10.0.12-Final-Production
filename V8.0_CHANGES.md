# Edge90 Analytics v8.0 — Adaptive Ensemble Optimizer

## New
- League-specific adaptive ensemble policies persisted under `models/`.
- Context profiles for BALANCED, DERBY, STRONG_MISMATCH and other learned regimes.
- Conservative shrinkage toward global validated weights.
- Minimum sample gates (80 calibration samples per regime).
- Walk-Forward evidence gate: at least 3 folds and 30 out-of-sample matches.
- Version and league protection prevents loading incompatible policies.
- Atomic JSON persistence.

## Safety
The optimizer never changes weights from future outcomes during prediction. If evidence is weak or a profile is sparse, the engine falls back to validated global weights.

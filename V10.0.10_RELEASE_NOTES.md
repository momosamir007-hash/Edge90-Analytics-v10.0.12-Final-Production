# v10.0.10 — High-Performance Temporal Benchmark Engine

## Goals
- Reduce repeated nested temporal-CV work during Walk-Forward benchmarking.
- Keep probability generation and final fitted pipeline semantics unchanged.
- Benchmark Argmax, Draw Threshold, Margin Based, Expected Cost and Contextual
  on exactly the same out-of-sample probabilities.
- Preserve resumability and leakage-safe chronological folds.

## Changes
1. `MLPred.train(..., temporal_cv=True)` now accepts an explicit diagnostic CV switch.
2. Resumable Walk-Forward benchmark path uses `temporal_cv=False` so each fold fits
   the same pipeline once instead of repeatedly fitting it inside TimeSeriesSplit.
3. Added `benchmark_v10_0_10.py` for fold-by-fold policy comparison and stability.
4. Added `test_v10_0_10_performance.py`.
5. Updated release metadata to v10.0.10.

## Safety
- This optimization does not feed evaluation outcomes into probability generation.
- Holdout results are not used to choose policies.
- Argmax remains the immutable fallback.
- Normal production training retains temporal CV by default.

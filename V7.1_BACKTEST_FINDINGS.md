# Edge90 Analytics v7.1 — Walk-forward findings

## What was tested
A chronological 70/30 holdout was run on each league. The diagnostic was intentionally run without the expensive ML layer so that the statistical ensemble could be evaluated quickly and reproducibly.

## Main finding
Elo was the strongest individual component across all five leagues in the evaluation window. The previous blend diluted this signal by giving relatively high weight to weaker components.

Individual-component accuracy in the same chronological evaluation window:

| League | Elo | Previous ensemble |
|---|---:|---:|
| Premier League | 52.90% | 49.70% |
| La Liga | 52.82% | 50.76% |
| Serie A | 52.16% | 49.09% |
| Bundesliga | 52.12% | 48.58% |
| Ligue 1 | 52.78% | 52.18% |

## v7.1 blend result (ML disabled)
The new weights reduce weak-signal dilution and produce the following holdout results:

| League | Accuracy | Brier |
|---|---:|---:|
| Premier League | 50.00% | 0.3083 |
| La Liga | 49.54% | 0.2978 |
| Serie A | 50.00% | 0.2980 |
| Bundesliga | 50.09% | 0.3016 |
| Ligue 1 | 52.35% | 0.2961 |

These are diagnostic historical results, not a guarantee of future accuracy.

## Important implementation fixes
- Downloader no longer regenerates active configuration with v5 model/calibration/Elo paths.
- Downloader fallback configuration now declares 126 features, matching v7.
- Active blend now gives Elo materially more weight and keeps ML at a controlled 15% when available.
- Weak fatigue/home-only components are deliberately down-weighted.
- The existing leakage-safe chronological backtest remains in place.

## Next optimization target
The next high-value experiment is a fully walk-forward ML comparison against the Elo/statistical baseline, followed by probability calibration using only information available before each prediction date. The ML layer should only receive more weight if it beats the baseline on out-of-sample log-loss/Brier, not merely training or shuffled-CV accuracy.

# Edge90 Analytics v7.7 — Probability Calibration 2.0 + Reliability Engine

## New calibration architecture
- Global multiclass temperature scaling remains the stable fallback.
- Temporal holdout is used before a regime or confidence-specific profile can activate.
- Separate profiles may be learned for match regimes and LOW / MEDIUM / HIGH confidence buckets.
- A local profile is accepted only when its holdout Log Loss beats the global calibrated baseline by a minimum margin.
- Sparse or unvalidated groups always fall back to the global calibrator.

## Reliability Engine
- Detects historically unstable confidence/regime segments from calibration data.
- Reduces reported confidence conservatively without changing the 1X2 probability ranking.
- Stores reliability reasons on each prediction.

## Meta-Learner integration fix
- The validated v7.6 Meta-Learner is now actually applied during prediction when active.
- Blend remains conservative: 55% Meta-Learner / 45% calibrated ensemble.

## Compatibility
- v7.7 calibration artifacts carry an explicit version marker.
- Older calibration files with usable history can be retrained into the v7.7 format.
- Meta-Learner artifact remains version-locked to v7.6 and is rejected if incompatible.

## Validation principle
No calibration or reliability profile is considered an improvement merely because it exists. The final criterion remains leakage-safe temporal / walk-forward Log Loss evaluation.

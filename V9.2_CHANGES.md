# Edge90 Analytics v9.2 — Data Quality & Integrity Engine

## Overview
v9.2 adds a conservative data-quality gate before model training and evaluation workflows.

## Added
- `DataQualityIntegrityEngine` with per-league reports.
- Detection of missing required fields, duplicate fixtures, conflicting fixtures and invalid dates.
- Detection of future-dated finished records and chronology anomalies as leakage-risk signals.
- Quality score and `healthy` / `warning` / `critical` status.
- Explicit `safe_for_training` recommendation; the engine does not silently alter source data.
- Version/league compatibility checks and atomic JSON persistence.

## Storage
`models/data_quality/<league>/data_quality_v9.2.json`

## Safety
The engine is observational and conservative. It does not invent or repair data, alter match probabilities, or bypass existing validation and promotion gates.

# v10.0.12 Final Release Notes

## Theme
**Final Production Hardening — Policy Equivalence + Dual Objective + Statistical Safety**

### Changes from v10.0.11
1. Added behavioral-equivalence protection against false policy upgrades.
2. Expected Cost is not promoted when it is behaviorally identical to Argmax.
3. Balanced objective now requires a material Macro-F1 gain by default.
4. Accuracy-First requires strict accuracy improvement and significant paired gain.
5. Argmax remains the canonical fallback whenever evidence is insufficient.
6. Version metadata is aligned to v10.0.12.
7. Added final release acceptance test.

## Acceptance principle
The final release does not claim that a more complex policy is better merely because it has a higher secondary metric. The production default is chosen conservatively from OOS evidence.

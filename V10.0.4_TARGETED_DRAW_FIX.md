# v10.0.4 — Targeted Draw Path Fix

## Root-cause hypothesis addressed
The forensic path identified weighted averaging as capable of suppressing independent draw evidence before the existing draw correction could activate.

## Fix
A conservative draw-evidence preservation step now runs immediately after the weighted ensemble and before draw correction. It activates only when:
- the specialized draw model materially exceeds ensemble P(Draw); and
- the fixture is sufficiently balanced and/or historically draw-prone.

The boost is capped at 4.5 percentage points and redistributes only probability mass from Home/Away. It does not force DRAW as the final class.

## Validation requirement
The fix must still be validated with the same chronological Walk-Forward protocol and must not be promoted solely because it raises Draw Recall. Log Loss, Brier, draw calibration and overall acceptance must all be rechecked.

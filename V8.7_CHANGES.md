# Edge90 Analytics v8.7 — Safe Artifact Promotion & Automatic Rollback

## New production safety layer
- Consumes only an explicit `promotion_approved` decision from v8.6.
- Backs up the current Champion artifact before any production change.
- Performs the candidate swap through a temporary artifact followed by an atomic replace.
- Runs model-load health checks before and after promotion.
- Automatically restores the previous Champion when the post-swap health check fails.
- Stores an auditable per-league promotion and rollback history under:
  `models/safe_promotion/<league>/artifact_promotion_v8.7.json`.

## Safety principle
A model can pass historical and live evaluation yet still fail artifact promotion if the candidate file is missing, empty, incompatible, or cannot be loaded safely. In every such case the Champion is retained or restored.

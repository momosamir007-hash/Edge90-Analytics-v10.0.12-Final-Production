# Edge90 Analytics v7.3 — Probability-First ML & Confidence Guard

## Changes
- ML model selection now optimizes temporal cross-validated log-loss instead of balanced accuracy.
- Removed class balancing from RF/LogisticRegression used for probability estimation; this avoids deliberately distorting class priors when calibrated probabilities are the goal.
- Weight optimization now uses 3 blocked folds inside the calibration window, reducing overfit to one contiguous calibration segment.
- Added evaluation log-loss alongside normalized multiclass Brier score.
- Added a conservative entropy-based confidence guard that shrinks only high-uncertainty probability vectors toward 1/3; it does not introduce look-ahead information.
- Kept evaluation fully chronological: evaluation matches remain unseen during ML training, calibration, and weight selection.

## Rationale
For football 1X2 forecasting, a model that is slightly less accurate in hard classification can still be better if its probabilities are better calibrated. v7.3 therefore treats probability quality as the primary ML objective and reports log-loss explicitly.

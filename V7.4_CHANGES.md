# Edge90 Analytics v7.4 — Deep Error Mining

## Goal
Turn the backtest into a diagnostic system that explains *where* confidence and component blending fail, without using evaluation outcomes to alter the same evaluation predictions.

## Changes
- Added `Backtester.deep_error_mining()`.
- Added confidence reliability bins (average confidence vs realised accuracy).
- Added high-confidence error extraction (>=60%).
- Added component disagreement/standalone accuracy diagnostics.
- Backtest prediction records now retain each component's 1X2 probabilities.
- JSON prediction export now includes `component_probabilities`.
- Existing leakage-safe chronological split remains unchanged.

## Safety
The new mining is post-evaluation diagnostics only. It must not be fed back into the same evaluation window. Use the findings to define the *next* calibration/training window.

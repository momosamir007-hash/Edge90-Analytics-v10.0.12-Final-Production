# v8.9 — Model Lifecycle Orchestrator

## Purpose
v8.9 unifies the lifecycle evidence created by v8.2 through v8.8 into one conservative, auditable state machine per league.

## Lifecycle stages
- stable_champion
- drift_detected
- retraining_pending
- challenger_registered
- shadow_evaluation
- promotion_review
- artifact_promoted
- canary_monitoring
- rolled_back

## Safety
The orchestrator does not override drift, validation, promotion, rollback, or canary safety gates. It only derives the current state from persisted evidence and recommends the next safe action.

## Storage
`models/lifecycle/<league>/model_lifecycle_v8.9.json`

All writes use atomic replacement and state history records stage transitions with timestamps and reasons.

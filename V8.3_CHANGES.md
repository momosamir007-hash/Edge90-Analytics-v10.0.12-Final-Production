# Edge90 Analytics v8.3 — Controlled Auto-Retraining Pipeline

## Pipeline
Drift recommendation → chronological data collection → temporal holdout → isolated candidate training → candidate validation → leakage-safe incumbent comparison → guarded promotion.

## Safety
- Production models are never overwritten before validation.
- Candidates are stored under `models/retraining/<league>/`.
- Promotion requires a measurable Log Loss improvement of at least 0.01.
- Existing legacy models without training-cutoff metadata cannot be used for unsafe incumbent comparisons; promotion is blocked rather than guessed.
- Promotion creates a backup and writes versioned training metadata.
- Every run produces an atomic, auditable JSON report.

# v9.0 — Autonomous Model Governance Engine

## Overview
Adds a central governance layer above v8.9 Model Lifecycle Orchestrator.

## Decision flow
Lifecycle State → Governance Policy → Risk Assessment → Action Approval → Execution

## Safety
- v9.0 does not bypass historical, shadow, live, promotion, artifact, or canary gates.
- Automatic artifact execution is disabled by default.
- Promotion transitions with elevated risk require explicit review.
- Every governance decision is persisted per league with atomic writes.

## Storage
`models/governance/<league>/model_governance_v9.0.json`

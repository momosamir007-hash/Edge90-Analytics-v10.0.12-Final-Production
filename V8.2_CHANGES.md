# Edge90 Analytics v8.2 — Automated Drift Detection & Model Retraining

## New
- Automated per-league data-drift detection using Population Stability Index (PSI).
- Performance-drift detection using chronological recent-vs-baseline Log Loss.
- Drift report is version- and league-protected and atomically saved.
- Conservative confidence reduction when drift is detected.
- Explicit retraining recommendation and scope instead of unsafe silent retraining.
- Requires adequate baseline and recent samples to avoid reacting to noise.

## Activation policy
- Data drift: PSI >= 0.25 for at least one monitored contextual feature.
- Performance drift: recent Log Loss deterioration >= 0.05.
- Retraining is recommended only when both drift types agree, or deterioration is severe.

## Safety
Production models are not silently overwritten. v8.2 produces an auditable retraining plan; a retraining workflow can consume that plan after validation.

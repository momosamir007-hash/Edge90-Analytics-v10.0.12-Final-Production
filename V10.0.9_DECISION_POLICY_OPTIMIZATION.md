# Edge90 Analytics v10.0.9 — Temporal Decision Policy Optimization

## Objective
Promote a classification policy only when it demonstrates stable, leakage-safe performance across multiple chronological out-of-sample folds.

## Changes
- Evaluate every policy on every temporal fold.
- Argmax remains the immutable classification baseline.
- Require at least 3 temporal folds before any challenger can be promoted.
- Add accuracy safety gate, draw-rate drift gate, macro-F1 gate, win-rate gate and worst-fold accuracy gate.
- Add policy stability diagnostics: accuracy std, macro-F1 std, draw precision/recall std.
- Fall back to Argmax when no challenger passes all gates.
- Preserve probability vectors and probability metrics unchanged.
- Add a temporal audit API that accepts chronologically ordered fold lists.

## Safety principle
The final/production holdout must not be used to select the policy. Policy selection is based only on historical walk-forward evidence.
